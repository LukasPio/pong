## Português (Brasil)

Baixe **pong-linux-x86_64** abaixo. SDL2, SDL2_ttf, FreeType e a fonte estão embutidos no executável. Funciona offline.

```sh
chmod +x pong-linux-x86_64
./pong-linux-x86_64
```

Requer Linux de 64 bits (Intel/AMD), glibc 2.35+ e uma sessão X11 ou Wayland com XWayland. Usa as bibliotecas gráficas e drivers do sistema. Compilado no Ubuntu 22.04; não é um binário para Alpine/musl.

**Controles:** W/↑ e S/↓ para mover; R para reiniciar após a partida; Esc ou - para sair.

## English

Download **pong-linux-x86_64** below and run the commands above. SDL2, SDL2_ttf, FreeType, and the font are embedded. Works offline.

Requires 64-bit Linux (Intel/AMD), glibc 2.35+, and X11 or Wayland with XWayland. Uses system graphics libraries and drivers. Built on Ubuntu 22.04; not compatible with Alpine/musl.

**Controls:** W/↑ and S/↓ to move; R to restart after a match; Esc or - to quit.
